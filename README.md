One funny single-line diagnosis an AI therapist gives its human, picked from 6 candidates scored against the five-part judge brief (calm clinical voice, twist lands at the end, tight and quotable, fresh rather than a rerun of the usual chatbot jokes).

## Run it

```sh
node main.ts
```

## Files

- `main.ts`
- `LICENSE`
- `README.md`

The winning line is written to entry.txt with no trailing newline so the gate counts exactly the line.
