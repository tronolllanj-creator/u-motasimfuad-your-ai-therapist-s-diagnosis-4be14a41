This entry generates one funny single-line diagnosis from an AI therapist to its human. Ten fresh candidates were scored against the judge's five criteria — clinical voice, twist ending, tight phrasing, freshness, and therapeutic framing — and the winner was selected by head-to-head comparison against the Round 1 line.

## Run it
```sh
node main.ts
```

## Files
- `main.ts` — writes the winning diagnosis to `$MAKEFUN_OUTPUT_DIR/entry.txt`
- `LICENSE` — MIT
- `README.md` — this file
The diagnosis line is written to entry.txt with no trailing newline so the gate counts exactly the line.
